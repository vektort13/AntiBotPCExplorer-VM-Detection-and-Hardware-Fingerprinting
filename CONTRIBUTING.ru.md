# Обратная связь и участие

Этот репозиторий — официальный центр документации и релизов AntiBotPCExplorer. Разработка приложения ведётся закрыто.

## Сообщить об ошибке

Создайте [сообщение об ошибке](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues/new?template=bug_report.yml). Укажите:

- Версию приложения и версию Windows.
- Страницу или операцию, с которой связана ошибка.
- Шаги воспроизведения, ожидаемое и фактическое поведение.
- Скриншот или небольшой фрагмент отчёта со скрытыми чувствительными значениями, если это поможет.

Идентификаторы скрыты по умолчанию. Просматривайте скриншоты и фрагменты отчётов перед прикреплением; сырые отчёты содержат исходные идентификаторы.

## Предложить возможность или задать вопрос

Для улучшений используйте [форму предложения](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues/new?template=feature_request.yml), а для вопросов по использованию — [форму поддержки](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues/new?template=question.yml). Опишите задачу, которую хотите решить, и ожидаемый результат.

Обратная связь принимается на английском, русском, вьетнамском и традиционном китайском языках.

## Улучшить документацию

Приветствуются pull request с исправлениями формулировок, переводов, скриншотов и неработающих ссылок. Сохраняйте согласованность четырёх версий README и соответствующей документации. Описания возможностей и скриншоты должны отражать опубликованную версию.

В публичный репозиторий не принимаются исходный код приложения, внутренние файлы сборки, учётные данные и сырые диагностические дампы. Для работы над документацией доступ к закрытому исходному коду приложения не требуется.

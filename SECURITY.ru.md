# Безопасность

## Поддерживаемый релиз

Сообщения о безопасности принимаются для последнего опубликованного релиза — сейчас это **1.4.0**. Скачать его можно в [GitHub Releases](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/releases/latest).

## Сообщить об уязвимости

Используйте [приватную форму GitHub для сообщений об уязвимостях](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/security/advisories/new), чтобы отправить информацию сопровождающим проекта.

Укажите версию приложения, версию Windows, шаги воспроизведения, наблюдаемые последствия и, по возможности, минимальный пример. Прикрепляйте только данные, необходимые для демонстрации проблемы. Подробности уязвимости и чувствительные вложения передавайте в приватном сообщении.

Для обычных ошибок и вопросов по использованию предназначен раздел [Issues](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues).

## Проверить загрузку

Официальные исполняемые файлы релизов подписаны цифровой подписью **Vektor T13 Technologies B.V.** Релиз содержит `SHA256SUMS.txt`; в [руководстве по установке](docs/ru/installation.md) описано, как сравнить хеш SHA-256 и проверить подпись Windows.

## Диагностические данные

Приложение собирает диагностику локально. По умолчанию идентификаторы скрыты в интерфейсе, а стандартный JSON-экспорт использует HMAC-теги. Сырые отчёты содержат исходные значения. В разделе [Приватность и отчёты](docs/ru/privacy.md) описаны локальное хранение, варианты экспорта и передача отчётов.

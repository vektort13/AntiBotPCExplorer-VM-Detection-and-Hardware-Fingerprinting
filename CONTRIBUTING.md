# Feedback and contributions

This repository is the official documentation and release hub for AntiBotPCExplorer. Application development takes place privately.

## Report a bug

Open a [bug report](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues/new?template=bug_report.yml). Include:

- The application version and Windows version.
- The page or operation involved.
- Steps to reproduce, expected behavior and actual behavior.
- A screenshot or small privacy-safe report excerpt, if useful.

Identifiers are hidden by default. Review screenshots and report excerpts before attaching them; raw reports contain original identifiers.

## Suggest a feature or ask a question

Use the [feature request form](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues/new?template=feature_request.yml) for improvements, or the [support form](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/issues/new?template=question.yml) for usage questions. Describe the task you want to accomplish and the result you expect.

Feedback is welcome in English, Russian, Vietnamese and Traditional Chinese.

## Improve the documentation

Pull requests for wording, translations, screenshots and broken links are welcome. Keep the four README editions and the corresponding documentation aligned. Product claims and screenshots should describe the published version.

The public repository does not accept application source code, internal build files, credentials or raw diagnostic dumps. Documentation contributions do not require access to the private application source.

## Report a vulnerability

Use the private channel described in [SECURITY.md](SECURITY.md).

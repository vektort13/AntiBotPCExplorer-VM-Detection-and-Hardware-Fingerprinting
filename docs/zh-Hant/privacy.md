# 隱私權與本機資料

[首頁](../../README.zh-Hant.md) · [安裝指南](installation.md) · [功能介紹](features.md) · [常見問題](faq.md)

## 本機運作

AntiBotPCExplorer 在執行程式的電腦上收集及分析資料。其介面內嵌於執行檔中。掃描、比較、簽章檢查與報告匯出均不會發出網路要求。內嵌的 WebView2 介面會封鎖導向其他頁面的瀏覽行為，並停用其背景網路活動與當機報告上傳。兩個產品網站按鈕會在預設瀏覽器中開啟 [anti.bot](https://anti.bot) 或 [detect.expert](https://detect.expert)。

掃描在使用者模式下執行，無須核心驅動程式。一般資料收集會讀取現有資料。選用的 TPM 金鑰動作、匯出的報告檔案與本機應用程式資料如下所述。

## 畫面上的數值

在您選擇並確認 **Show identifiers（顯示識別碼）** 之前，介面會隱藏標示為敏感的欄位。這些欄位包括序號、硬體 UUID、MAC 位址、金鑰指紋，以及部分個人或網路資訊。「原始 JSON」頁面也遵循相同的設定。

系統背景資訊、型號名稱、安全性狀態、診斷結果及未標示為敏感的欄位仍會顯示。在畫面上顯示數值不會改變匯出模式。

## 報告格式

| 匯出格式 | 內容 |
| --- | --- |
| 隱私保護報告 | 以 HMAC-SHA256 標記取代敏感欄位；省略不包含在安全匯出中的表格 |
| 原始診斷報告 | 收集到的原始數值，包括敏感識別碼 |

隱私保護格式會保留實用的診斷背景資訊，並透過一致的標記進行比較。其中包含系統資訊及未標示為敏感的識別碼。只有在您選擇匯出動作，或提供命令列輸出路徑時，程式才會儲存報告。

HMAC 金鑰在本機產生。使用同一金鑰的兩份報告，可以比較其受保護的數值。若報告使用不同金鑰，比較工具會將這些數值標示為無法比較。

## 儲存的檔案

預設的本機資料目錄為：

```text
%LOCALAPPDATA%\AntiBotPCExplorer
```

若該目錄無法使用，應用程式會使用 `%TEMP%\AntiBotPCExplorer`。

| 檔案或資料夾 | 用途 |
| --- | --- |
| `hmac.key` | 用於為報告中的敏感數值產生穩定標記的本機金鑰 |
| `language.txt` | 儲存的介面語言 |
| `WebView2\` | 內嵌介面的瀏覽器設定檔 |

JSON 報告會寫入您在「儲存」對話方塊中選擇的路徑，或命令列指定的路徑，與設定目錄分開儲存。

若要重設本機應用程式資料，請先關閉程式，再刪除其資料目錄。這會重設語言與 HMAC 金鑰。重設前後匯出的報告，將無法再透過標記比對受保護的數值。若無法讀取現有的金鑰檔案，程式會將其保留，並在目前工作階段使用暫存金鑰。

## 選用的 TPM 金鑰

只有在您選擇建立動作時，TPM 頁面才會建立不可匯出的示範金鑰 `AntiBotPCExplorer-DeviceKey`。**Delete key（刪除金鑰）**可將其移除。刪除執行檔或本機資料目錄，不會移除此 TPM 金鑰。

`--selftest` 命令會使用另一個暫存金鑰，對挑戰值進行簽署與驗證，並在結束後移除測試金鑰。

## 不會收集的資料

此檢視工具不會讀取 Windows 產品金鑰、BitLocker 資料、Windows Hello 金鑰容器、TPM 擁有者授權資訊，或 IMSI、ICCID 等行動通訊用戶識別碼。Windows 授權資訊僅限於描述性狀態與識別碼，不包含產品金鑰。OneDrive 檢查會讀取相關的裝置識別碼，而非帳戶內容。

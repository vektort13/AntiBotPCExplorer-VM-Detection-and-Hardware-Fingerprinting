# 功能介紹

[首頁](../../README.zh-Hant.md) · [安裝指南](installation.md) · [常見問題](faq.md) · [隱私權與本機資料](privacy.md)

AntiBotPCExplorer 將裝置身分、硬體清單與 Windows 平台安全性整合到單一本機檢視工具中。程式在使用者模式下執行，使用既有的 Windows 介面，無須核心驅動程式。

## 四項可檢視依據的分數

總覽為每個面向顯示 0 到 100 的分數，並在下方列出影響分數的項目。

| 分數 | 說明 |
| --- | --- |
| 裝置身分 | 可用的硬體與安裝識別依據，包括 TPM、韌體、儲存裝置與網路識別碼 |
| 平台完整性 | 開機與核心保護證據：TPM、安全開機、VBS、HVCI、IOMMU 及相關設定 |
| 驅動程式信任度 | 執行中核心驅動程式的簽章類別與系統程式碼完整性設定 |
| 實體電腦可信度 | 虛擬化證據、資料來源可用性，以及構成結果的獨立證據群組 |

分數依加權規則計算，各頁面均會顯示底層觀察結果與檢查項目。

## 虛擬機器偵測

專屬的虛擬機器偵測頁面會將客體與雲端基礎架構的證據分類整理。每項已執行的檢查都包含狀態、權重、分數貢獻及技術細節。頁面也提供涵蓋 100 種方法與 10 項弱啟發式判斷的目錄，列出各自的實作狀態，並連結至相關的已執行檢查。

模型會將相關的觀察結果分組，避免彼此關聯的韌體或裝置訊號重複提供同一份證據。在實體主機上執行的 Hyper-V 或 VBS，會依其主機情境解讀。遠端工作階段，以及偵錯工具、Sandboxie、Comodo 和 Wine 的被動檢查，會作為背景資訊顯示，其虛擬機器分數權重為零。

## 硬體與系統清單

| 頁面 | 重點資訊 |
| --- | --- |
| 識別碼 | 找到的識別碼、其唯一性範圍、權重、身分資訊群組與來源 |
| CPU 與 FPU | CPU 功能、邏輯處理器拓撲、快取與確定性浮點運算特徵 |
| 韌體 | SMBIOS、ACPI、韌體更新資訊、安全開機憑證與開機組態 |
| 儲存裝置 | 磁碟與控制器識別碼、多種儲存裝置查詢途徑、分割區與磁碟區 |
| 網路 | 目前與永久 MAC 位址、介面識別碼、已知網路、藍牙裝置與行動數據機資訊 |
| 顯示與電源 | 圖形介面卡、已連接的顯示器、EDID、顯示模式與電池 |
| PnP 裝置 | 裝置識別碼、驅動程式、PCIe 連線資訊、音訊端點、生物辨識感應器、智慧卡讀卡機與印表機 |
| TPM | TPM 屬性、背書金鑰與憑證、PCR、測量開機記錄與 Windows 佈建記錄 |
| 平台安全性 | 安全開機、VBS/HVCI、程式碼完整性、IOMMU 與資訊安全中心產品狀態 |
| Microsoft 與雲端 | Windows 授權狀態、Microsoft 服務識別碼、Entra 加入、MDM/Intune 與 Autopilot 資訊 |
| 核心驅動程式 | 執行中的核心驅動程式、簽章分類與發行者摘要 |
| Windows | 安裝識別碼、作業系統資訊、升級沿革、使用者設定檔中繼資料與電腦憑證 |
| 原始 JSON | 目前的本機快照；敏感數值是否顯示會遵循介面的顯示設定 |

可取得的詳細資訊取決於硬體、Windows 組態與存取權限。無法取得的資料來源會在介面中顯示明確的狀態訊息。

## 獨立交叉檢查

應用程式會比較透過不同來源取得的觀察結果。例如比對 CPU 資訊與韌體、圖形介面卡與裝置清單、目前與永久網路位址、不同查詢方法取得的儲存裝置序號，以及 TPM 資訊與韌體及 Windows 記錄。測量開機事件可以重播，並與目前的 PCR 值比對。發現不一致時，會與觀察結果一併顯示。

## 比較快照

載入兩份已儲存的 JSON 報告，或在任一比較欄位使用目前的掃描結果。應用程式會比較 TPM、主機板、儲存裝置、網路、圖形硬體、韌體、CPU、Windows 安裝與記憶體等身分資訊群組。

結果包含吻合分數與各群組的詳細分析。內建模擬情境可讓您探索重新安裝 Windows、升級元件或更換硬體對比較結果的影響。您也可以按下按鈕，將同一組報告送至「報告差異」開啟。

## 報告差異

逐欄比較兩份報告：報告中繼資料、分數與影響分數的項目、交叉檢查、識別碼及表格。變更的欄位與僅存在於其中一份報告的資料列會以紅色標示。篩選器可僅顯示差異，並忽略掃描時間或開機運作時間等易變動欄位。區段連結可直接跳至對應的比較表格。

您可以使用檔案選擇器載入報告，或將 JSON 檔案拖曳到比較欄位。敏感數值會保持隱藏，直到您選擇 **Show identifiers（顯示識別碼）**。使用同一本機金鑰的報告可比較受保護的識別碼；以不同金鑰保護的數值則會標示為無法比較。

## 報告與語言

您可以匯出以 HMAC 標記取代敏感欄位的隱私保護 JSON 報告，或含有收集到的原始數值的原始 JSON 報告。兩種格式都可以重新載入比較工具。資料收集與匯出也可透過[命令列](installation.md)執行。

執行檔包含完整介面及九種語言：英文、俄文、越南文、簡體中文、繁體中文、西班牙文、巴西葡萄牙文、法文與德文。

## 選用的 TPM 金鑰示範

TPM 頁面可以建立不可匯出的 ECDSA P-256 示範金鑰、對新產生的挑戰值進行簽署及驗證，並刪除金鑰。這些動作僅會在您要求時執行。`--selftest` 命令會使用另一個暫存金鑰完成一次簽署與驗證流程，並在結束後移除測試金鑰。

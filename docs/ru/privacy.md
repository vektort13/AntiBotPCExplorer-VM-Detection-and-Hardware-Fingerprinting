# Приватность и локальные данные

[Главная](../../README.ru.md) · [Установка](installation.md) · [Возможности](features.md) · [Вопросы и ответы](faq.md)

## Локальная работа

AntiBotPCExplorer собирает и анализирует данные на компьютере, где он запущен. Интерфейс встроен в исполняемый файл. Сканирование, сравнение, проверка подписей и экспорт отчётов не делают сетевых запросов. Встроенный интерфейс WebView2 блокирует переходы на другие страницы; фоновая сетевая активность и отправка отчётов о сбоях отключены. Две кнопки сайтов продукта открывают [anti.bot](https://anti.bot) или [detect.expert](https://detect.expert) в браузере по умолчанию.

Сканирование выполняется в пользовательском режиме без драйвера ядра. Обычный сбор читает существующие данные. Дополнительные действия с TPM-ключом, экспортируемые файлы отчётов и локальные данные приложения описаны ниже.

## Значения на экране

Интерфейс скрывает поля, отмеченные как чувствительные, до выбора **Show identifiers** и подтверждения. К ним относятся серийные номера, аппаратные UUID, MAC-адреса, отпечатки ключей и отдельные личные или сетевые сведения. Страница Raw JSON следует той же настройке.

Системный контекст, названия моделей, состояние безопасности, результаты диагностики и поля без отметки чувствительности остаются открытыми. Раскрытие значений на экране не меняет режим экспорта.

## Форматы отчётов

| Экспорт | Содержимое |
| --- | --- |
| Privacy-safe report | Чувствительные поля заменены HMAC-SHA256-тегами; таблицы, исключённые из этого вида экспорта, отсутствуют |
| Raw diagnostic report | Исходные собранные значения, включая чувствительные идентификаторы |

Формат privacy-safe сохраняет полезный диагностический контекст и позволяет сравнивать отчёты благодаря стабильным тегам. Он включает системные сведения и идентификаторы, не отмеченные как чувствительные. Отчёт сохраняется только после выбора действия экспорта или указания пути вывода в командной строке.

Ключ HMAC создаётся локально. Два отчёта с одним ключом позволяют сопоставлять защищённые значения. Если ключи различаются, инструменты сравнения отмечают такие значения как несопоставимые.

## Хранимые файлы

Основная папка локальных данных:

```text
%LOCALAPPDATA%\AntiBotPCExplorer
```

Если эта папка недоступна, приложение использует `%TEMP%\AntiBotPCExplorer`.

| Файл или папка | Назначение |
| --- | --- |
| `hmac.key` | Локальный ключ для стабильных тегов чувствительных значений в отчётах |
| `language.txt` | Сохранённый язык интерфейса |
| `WebView2\` | Браузерный профиль встроенного интерфейса |

JSON-отчёты записываются по пути, выбранному в диалоге сохранения или переданному в командной строке. Они хранятся отдельно от папки настроек.

Для сброса локальных данных закройте программу и удалите её папку данных. Это сбросит язык и ключ HMAC. Защищённые значения в отчётах, экспортированных до и после сброса, больше нельзя будет сопоставить по тегам. Если существующий файл ключа не удаётся прочитать, он остаётся на месте, а текущая сессия использует временный ключ.

## Дополнительные TPM-ключи

Страница TPM создаёт неэкспортируемый демонстрационный ключ `AntiBotPCExplorer-DeviceKey` только после выбора действия создания. Кнопка **Delete key** удаляет его. Удаление исполняемого файла или локальной папки данных не удаляет этот TPM-ключ.

Команда `--selftest` использует отдельный временный ключ, подписывает и проверяет проверочный запрос, затем удаляет свой тестовый ключ.

## Какие данные не собираются

Инспектор не читает ключи продукта Windows, данные BitLocker, контейнеры ключей Windows Hello, авторизационные данные владельца TPM и сотовые идентификаторы абонента, такие как IMSI и ICCID. Сведения о лицензировании Windows ограничены описанием состояния и идентификаторами, без ключей продукта. При проверке OneDrive читаются относящиеся к устройству идентификаторы, а не содержимое учётных записей.

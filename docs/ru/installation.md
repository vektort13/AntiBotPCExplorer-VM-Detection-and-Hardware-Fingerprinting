# Установка и первый запуск

[Главная](../../README.ru.md) · [Возможности](features.md) · [Вопросы и ответы](faq.md) · [Приватность и локальные данные](privacy.md)

## Требования

| Компонент | Требование |
| --- | --- |
| Операционная система | Windows 10 или Windows 11, 64-разрядная x64 |
| Приложение | Один портативный исполняемый файл; установщик и .NET не требуются |
| Графический интерфейс | Microsoft Edge WebView2 Runtime |
| Права | Обычная учётная запись для стандартной диагностики; дополнительное повышение прав для отдельных источников |

Интерфейс и все девять переводов встроены в исполняемый файл. WebView2 Runtime входит в Windows 11. Если программа сообщает, что WebView2 не удалось запустить, установите x64 Evergreen Runtime со [страницы загрузки Microsoft WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) и снова откройте приложение.

## Скачать и запустить

1. Откройте [последний релиз](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/releases/latest).
2. Скачайте `AntiBotPCExplorer-1.4.0-x64.exe` из раздела **Assets** и сохраните в удобную папку.
3. Дважды щёлкните по исполняемому файлу. Сбор данных начнётся автоматически; после завершения сканирования откроется Overview.
4. Через боковую панель изучайте оборудование, системные идентификаторы, безопасность платформы, драйверы и признаки виртуальных машин.

[Скачать исполняемый файл](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/releases/latest/download/AntiBotPCExplorer-1.4.0-x64.exe) · [Все релизы](https://github.com/vektort13/AntiBotPCExplorer-VM-Detection-and-Hardware-Fingerprinting/releases)

Приложение собирает данные локально. Для сканирования не нужны учётная запись продукта и подключение к интернету.

## Проверить загрузку

Скачайте файл контрольных сумм SHA-256 из релиза вместе с исполняемым файлом. В PowerShell вычислите хеш загруженного файла:

```powershell
Get-FileHash .\AntiBotPCExplorer-1.4.0-x64.exe -Algorithm SHA256
```

Сравните результат со строкой для этого же файла в списке контрольных сумм.

Исполняемый файл подписан цифровой подписью **Vektor T13 Technologies B.V.** Для проверки подписи в PowerShell:

```powershell
Get-AuthenticodeSignature .\AntiBotPCExplorer-1.4.0-x64.exe | Format-List Status,SignerCertificate
```

Windows должна показать статус `Valid`. Также можно открыть вкладку **Свойства → Цифровые подписи** у файла.

## Работа с интерфейсом

| Действие | Управление |
| --- | --- |
| Изменить язык интерфейса | Кнопка с флагом на верхней панели или страница About |
| Найти данные на текущей странице | `Ctrl+F`; поиск по английским названиям и их переводам |
| Собрать новый снимок | `F5` |
| Показать чувствительные идентификаторы | **Show identifiers**, затем подтверждение |
| Сохранить отчёт | **Export** → **Privacy-safe report** или **Raw diagnostic report** |
| Прочитать дополнительные защищённые источники | **Restart as administrator** в приложении |

В меню языка доступны английский, русский, вьетнамский, упрощённый и традиционный китайский, испанский, бразильский португальский, французский и немецкий. При первом запуске язык выбирается по настройкам Windows, а затем программа запоминает ваш выбор.

Повышение прав открывает доступ к таким источникам, как переменные UEFI Secure Boot, загрузочная конфигурация, ATA Identify, аппаратный хеш Autopilot и история известных сетей. Если защищённый источник недоступен для чтения, остальные разделы продолжают работать, а в соответствующей строке указана причина.

## Экспорт без открытия окна

Эти команды используют нативный сборщик и не требуют WebView2. Поскольку исполняемый файл относится к приложениям с графическим интерфейсом, `Start-Process -Wait` заставляет PowerShell дождаться записи отчёта.

```powershell
Start-Process .\AntiBotPCExplorer-1.4.0-x64.exe -ArgumentList '--export','report.json' -Wait -NoNewWindow
```

Для сырого отчёта с исходными значениями идентификаторов:

```powershell
Start-Process .\AntiBotPCExplorer-1.4.0-x64.exe -ArgumentList '--export-raw','raw.json' -Wait -NoNewWindow
```

Если абсолютный путь не указан, путь вывода отсчитывается от рабочего каталога процесса. Выберите папку, доступную для записи. Если путь содержит пробелы, заключите его в кавычки внутри строки аргументов:

```powershell
Start-Process .\AntiBotPCExplorer-1.4.0-x64.exe -ArgumentList '--export "C:\Reports Folder\report.json"' -Wait -NoNewWindow
```

Открыть интерфейс на выбранном языке:

```powershell
.\AntiBotPCExplorer-1.4.0-x64.exe --lang zh-Hant
```

Поддерживаемые коды языков: `en`, `ru`, `vi`, `zh-Hans`, `zh-Hant`, `es`, `pt`, `fr`, `de`.

## Обновление и удаление

Для обновления закройте приложение и скачайте новый исполняемый файл из Releases. Локальные настройки хранятся отдельно от исполняемого файла, поэтому замена программы сохраняет выбранный язык и ключ для сравнения защищённых идентификаторов.

Чтобы удалить программу, удалите исполняемый файл. Для удаления локальных настроек и профиля WebView2 также закройте программу и удалите `%LOCALAPPDATA%\AntiBotPCExplorer`. При этом сбрасывается ключ сравнения отчётов. Идентификаторы, защищённые HMAC, в отчётах до и после сброса больше нельзя будет сопоставить. В разделе [Приватность и локальные данные](privacy.md) приведён полный список хранимых файлов и сведения о дополнительном демонстрационном ключе TPM.

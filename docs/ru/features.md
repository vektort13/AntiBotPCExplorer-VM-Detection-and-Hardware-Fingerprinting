# Возможности

[Главная](../../README.ru.md) · [Установка](installation.md) · [Вопросы и ответы](faq.md) · [Приватность и локальные данные](privacy.md)

AntiBotPCExplorer объединяет сведения об идентичности устройства, инвентаризацию оборудования и безопасность платформы Windows в одном локальном инспекторе. Он работает в пользовательском режиме, использует существующие интерфейсы Windows и не требует драйвера ядра.

## Четыре оценки с пояснениями

Overview показывает оценку от 0 до 100 по каждому направлению; ниже перечислены повлиявшие на неё пункты.

| Оценка | Что она описывает |
| --- | --- |
| Device identity — идентичность устройства | Доступные аппаратные и установочные якоря, включая TPM, прошивку, накопители и сетевые идентификаторы |
| Platform integrity — целостность платформы | Данные о защите загрузки и ядра: TPM, Secure Boot, VBS, HVCI, IOMMU и связанные настройки |
| Driver trust — доверие к драйверам | Классы подписей работающих драйверов ядра и настройки целостности кода системы |
| Physical PC Confidence — уверенность в физическом ПК | Признаки виртуализации, доступность источников и независимые группы свидетельств, на которых основан результат |

Оценки рассчитываются по взвешенным правилам, а на каждой странице доступны исходные наблюдения и проверки.

## VM Detection

Отдельная страница VM Detection распределяет по категориям признаки гостевой системы и облачной инфраструктуры. Каждая выполненная проверка содержит статус, вес, вклад в оценку и техническое описание. На странице также есть каталог из 100 методов и десяти слабых эвристик со статусом реализации и ссылками на соответствующие выполненные проверки.

Модель объединяет связанные наблюдения в группы, чтобы коррелирующие признаки прошивки или устройств не учитывали одно и то же свидетельство повторно. Hyper-V или VBS, работающие на физическом хосте, рассматриваются с учётом этого контекста. Удалённые сеансы и пассивные проверки отладчика, Sandboxie, Comodo и Wine отображаются как контекст с нулевым весом в VM-оценке.

## Инвентаризация оборудования и системы

| Страница | Основные сведения |
| --- | --- |
| Identifiers | Найденные идентификаторы, область уникальности, вес, группа идентичности и источник |
| CPU & FPU | Возможности CPU, топология логических процессоров, кеши и детерминированные профили вычислений с плавающей точкой |
| Firmware | SMBIOS, ACPI, сведения об обновлении прошивки, сертификаты Secure Boot и загрузочная конфигурация |
| Storage | Идентификаторы дисков и контроллеров, разные способы опроса накопителей, разделы и тома |
| Network | Текущие и постоянные MAC-адреса, идентификаторы интерфейсов, известные сети, Bluetooth-устройства и сведения о мобильных модемах |
| Display & power | Графические адаптеры, подключённые дисплеи, EDID, видеорежимы и батареи |
| PnP devices | Идентификаторы устройств, драйверы, параметры PCIe-соединения, аудиоконечные точки, биометрические сенсоры, считыватели смарт-карт и принтеры |
| TPM | Свойства TPM, ключи и сертификаты подтверждения, PCR, журнал Measured Boot и записи Windows о провижининге |
| Platform security | Secure Boot, VBS/HVCI, целостность кода, IOMMU и состояние продуктов Центра безопасности |
| Microsoft & cloud | Состояние лицензирования Windows, идентификаторы сервисов Microsoft, присоединение Entra, сведения MDM/Intune и Autopilot |
| Kernel drivers | Работающие драйверы ядра, классы подписей и сводка по издателям |
| Windows | Идентификаторы установки, сведения об ОС, история обновлений, метаданные пользовательских профилей и сертификаты компьютера |
| Raw JSON | Текущий локальный снимок; чувствительные значения отображаются в соответствии с настройкой раскрытия идентификаторов |

Доступная детализация зависит от оборудования, конфигурации Windows и прав доступа. Для недоступных источников интерфейс показывает явные сообщения о состоянии.

## Независимые кросс-проверки

Приложение сопоставляет наблюдения из разных источников. Например, сведения о CPU сравниваются с прошивкой, графические адаптеры — с перечнем устройств, текущие сетевые адреса — с постоянными, серийные номера накопителей — между разными способами опроса, а информация TPM — с прошивкой и записями Windows. События Measured Boot можно воспроизвести для сверки с текущими PCR. Расхождения показываются рядом с наблюдениями.

## Compare snapshots — сравнение снимков

Загрузите два сохранённых JSON-отчёта или используйте текущий скан в любом из двух слотов. Приложение сравнивает группы идентичности: TPM, материнскую плату, накопители, сеть, графику, прошивку, CPU, установку Windows и память.

Результат включает оценку совпадения и разбивку по группам. Встроенные сценарии симуляции показывают, как переустановка Windows, обновление компонентов или замена оборудования влияют на сравнение. Отдельная кнопка открывает ту же пару отчётов в Report diff.

## Report diff — различия отчётов

Сравнивайте два отчёта по полям: метаданные, оценки и повлиявшие на них пункты, кросс-проверки, идентификаторы и таблицы. Изменённые поля и строки, присутствующие только в одном отчёте, выделяются красным. Фильтры позволяют показать только различия и исключить изменчивые поля, например время сканирования или время работы системы. Ссылки разделов ведут прямо к нужной таблице сравнения.

Отчёты можно загрузить через диалог выбора файла или перетащить JSON-файл на слот. Чувствительные значения остаются скрытыми, пока вы не выберете **Show identifiers**. В отчётах с одним локальным ключом защищённые идентификаторы можно сопоставлять; значения, защищённые разными ключами, помечаются как несопоставимые.

## Отчёты и языки

Экспортируйте JSON-отчёт, в котором чувствительные поля заменены HMAC-тегами, или сырой JSON-отчёт с исходными собранными значениями. Оба формата можно снова загрузить в инструменты сравнения. Сбор и экспорт также работают из [командной строки](installation.md).

Исполняемый файл содержит полный интерфейс на девяти языках: английском, русском, вьетнамском, упрощённом и традиционном китайском, испанском, бразильском португальском, французском и немецком.

## Дополнительная демонстрация TPM-ключа

На странице TPM можно создать неэкспортируемый демонстрационный ключ ECDSA P-256, подписать и проверить новый проверочный запрос и удалить ключ. Эти действия выполняются только по запросу. Команда `--selftest` проводит отдельную проверку с временным ключом и затем удаляет его.
